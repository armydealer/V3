# راهنمای نصب و اجرای شخصی شیرین‌تراز (۱۰۰٪ آفلاین، بدون نیاز به جمینای)

این برنامه هیچ نیازی به **کلید API، اتصال به جمینای (Gemini)، سرور ابری یا اینترنت** ندارد. تمام محاسبات و اطلاعات کارگاه روی مرورگر و سیستم شخصی خودتان ذخیره می‌شود.

## روش ۱: نصب مستقیم به عنوان اپلیکیشن (PWA) روی ویندوز، مک، اندروید یا آیفون
1. برنامه را در مرورگر کروم (Chrome) یا اج (Edge) باز کنید.
2. روی دکمه **«نصب روی سیستم»** در نوار بالای برنامه یا صفحه **«نصب و بکاپ»** کلیک کنید.
3. از این به بعد آیکون **شیرین‌تراز** روی دسکتاپ یا صفحه موبایل شما قرار می‌گیرد و حتی **بدون اینترنت** کار می‌کند.

## روش ۲: اجرای مستقل روی کامپیوتر شخصی کاربر (ویندوز / مک / لینوکس)
کافی است فقط **Node.js** (نسخه ۱۸ به بالا) روی سیستم نصب باشد:

```bash
# ۱. نصب کتابخانه‌ها (فقط یک‌بار در ابتدا)
npm install

# ۲. ساخت نسخه نهایی آفلاین
npm run build

# ۳. اجرای برنامه روی سیستم شخصی
npm start
```

سپس مرورگر را باز کرده و آدرس زیر را وارد کنید:
`http://localhost:3000`

> نکته: برای پشتیبان‌گیری یا انتقال اطلاعات به سیستم دیگر، از بخش **«نصب و بکاپ»** دکمه **«دانلود فایل پشتیبان (JSON)»** را بزنید.
